# DialBack design (starter)

React SPA with a public landing page and a workspace shell. Feature pages are composed from reusable layout, navigation, heading, status, service-card and feature-card components. Bundled service data feeds the directory, USSD menu and local assistant. localStorage stores demo preferences, favourites and activity. A PWA service worker precaches the app shell and static assets.

Visual direction: deep navy foundation, electric purple and cyan accents, restrained gradients, readable type, clear focus states and purposeful motion.
